# Agents

Contributors work with different agents, such as Claude Code, Codex or OpenCode.
This file applies to all of them.

The specs in `docs/specs` define what every port does. Agents ask the developer
before they add or edit a spec.

Commits carry no agent trailers, such as `Co-Authored-By` or a session link.
The pull request description ends with a rule and a line that names the agent
and the model, without links:
